## 1. 배경

1차 납품된 캐릭터(`Resources/characters/<id>/portrait.png` 등)는 검증을 통과해 앱에 반영됐습니다. 지금은 편지 제목 옆에 캐릭터 얼굴만 뜹니다. 이번에는

1. **편지 머리 배경 그림** — 종이 맨 위에 가로로 꽉 차는 도트 풍경을 깔고, 그 위에 1차 캐릭터(말하는 얼굴)가 서 있는 구성으로 만들고 싶습니다.
2. **도트 인장** — 편지 오른쪽 아래에 찍히는 인장이 지금은 벡터(SVG)라 캐릭터와 화풍이 다릅니다. 같은 도트 화풍으로 바꿔 주십시오.

연동은 이쪽에서 이미 준비했습니다. 아래 규격의 파일이 폴더에 들어오면 앱이 자동으로 쓰고, 없으면 지금 모습 그대로입니다.

## 2. 만들어야 할 것

폴더는 그대로 `Resources/characters/<id>/` 입니다. **이 폴더 밖은 건드리지 마십시오.**

| 파일 | 원본(작업) 크기 | **납품 크기** (정확히 4배, nearest) | 용도 |
|---|---|---|---|
| `header.png` | 240×80 | **960×320** | 편지 머리 배경. 종이 폭(약 680px)에 맞춰 `cover`로 깔리고 높이 224px로 보입니다 |
| `seal.png` | 64×64 | **256×256** | 편지 오른쬬 아래 인장. 78×78px로 보입니다 |

### header.png — 배경 풍경 지시

- 가로로 긴 **풍경/실내 장면**. 화면 **왼쪽 아래 약 130×130px 영역(원본 기준 약 34×34)은 캐릭터가 서는 자리**이므로 바닥·마루·땅처럼 비워 두고, 그 위에 물건을 놓지 마십시오. 캐릭터는 배경 위에 겹쳐 그려집니다(배경 그림 안에 캐릭터를 넣지 마십시오).
- 아래쪽 1/3은 어둡거나 단순하게, 위쪽은 하늘·벽 등 열린 공간으로 — 그래야 캐릭터와 제목이 읽힙니다.
- 인물당 팔레트 16~24색, 1차 캐릭터와 같은 외곽선·명암 규칙. 글자 없음. **투명 배경이 아니라 꽉 채운 장면**입니다(알파는 전부 불투명).

| id | 장면 | 색조 |
|---|---|---|
| `zhuge` | 촉의 군막 안. 책상 위 지도와 등불, 뒤로 산과 안개, 깃발 | 한지빛·먹·주홍 `#9b2226`, 나무 `#4a3524` |
| `socrates` | 아테네 아고라. 흰 대리석 기둥, 올리브 나무, 푸른 하늘, 멀리 아크로폴리스 | 대리석 `#f4f1ea`, 올리브 `#5b6b4a`, 테라코타 `#b5532a`, 에게해 청 |
| `nietzsche` | 알프스 호숫가(실스마리아). 검푸른 산, 소나무, 노을 혹은 밤, 작은 오두막 창의 불빛 | 검정 `#151312`, 금 `#c9a24a`, 붉은 `#c8322e` 한 점 |
| `sejong` | 경복궁 근정전 마당 또는 집현전 서가. 청록 기와, 단청, 돌 마당, 책 서가 | 청록 `#1f6f6b`, 금 `#c39a3b`, 비단 `#f3ecd9`, 단청 적색 |

### seal.png — 도트 인장 지시

- 64×64 안에 **네모난 도장 자국**. 살짝 기울여도 좋음(±5°). 찍힌 자국이라 가장자리가 조금 뭉개진 느낌(픽셀 몇 개 빠진 정도).
- 글자는 **한글**로 새김: 제갈량 → "제갈공명"(2×2), 소크라테스 → "소크라테스"(세로 또는 2줄), 니체 → "니체", 세종 → "세종 어보". 한자·로마자 없음.
- 색: 제갈량 주홍 `#9b2226` 바탕 + 한지색 글자 / 소크라테스 올리브 `#5b6b4a` 원형 메달 + 대리석색 글자 / 니체 검정 바탕 + 금 `#c9a24a` 글자, 붉은 테 / 세종 청록 `#1f6f6b` 바탕 + 금 테 + 비단색 글자.
- 배경 **투명**(RGBA).

## 3. 작업 방법

1차와 같습니다. 큰 원화를 생성 → 원본 해상도(240×80, 64×64)로 nearest 축소 + 양자화 → 4배 nearest 확대 → 저장. 배경은 `header.png`만 불투명이고 `seal.png`는 투명입니다.

캐릭터가 서는 자리를 확인하려면, 납품 전에 다음처럼 겹쳐 봐 주십시오.

```python
from PIL import Image
bg = Image.open("Resources/characters/zhuge/header.png").convert("RGBA")   # 960×320
ch = Image.open("Resources/characters/zhuge/portrait.png").convert("RGBA")  # 256×256
bg.alpha_composite(ch, (50, 320 - 256))        # 왼쪽 아래
bg.save("docs/screenshots/header-check-zhuge.png")
```
