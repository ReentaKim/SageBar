## 이쪽에서 조정한 것 (CSS, 자산 재작업 없음)

1. **패널 안쪽 여백** — 그림 틀이 CSS 테두리보다 두꺼워 "장부"·"메뉴" 제목이 왼쪽 테두리에 걸렸습니다. 그림 모드일 때만 안쪽 여백을 늘려 해결했습니다.
2. **서가 다발 높이** — 다발이 선반 판보다 살짝 떠 보여, 배경 그림의 판 높이에 맞춰 내렸습니다.
