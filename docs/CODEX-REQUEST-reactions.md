## 1. 배경

SageBar 0.5.0에 두 기능이 들어갑니다.

1. **지난 조언 점검** — 편지 첫머리에 "지난 글에서 권한 것을 그 뒤 대화로 확인해 했는지/안 했는지" 짚는 상자가 생깁니다. 이 상자 왼쪽에 **그 인물의 표정**이 붙습니다. 대체로 했으면 흡족한 얼굴, 대체로 안 했으면 꾸짖는 얼굴입니다.
2. **피드백 버튼** — 편지 아래에 "찔렸다 / 뻔했다" 두 버튼이 생깁니다. 버튼 앞에 작은 도트 아이콘, 누른 뒤에는 "새겨 두겠습니다" 문구 옆에 작은 도장이 찍힙니다.

연동은 준비되어 있습니다. 파일이 들어오면 자동으로 쓰고, 없으면 표정 자리에는 기존 초상이, 버튼에는 글자만 나옵니다.

### 먼저 볼 것

| 파일 | 내용 |
|---|---|
| `Resources/characters/<id>/portrait.png`, `talking.png` | 1차 초상. **표정은 이 얼굴과 같은 인물·같은 앵글·같은 팔레트**여야 합니다. talking 1번 프레임(입 닫힘)을 기준으로 눈·입·눈썹만 바꾸는 식이 가장 안전합니다 |
| `Resources/characters/<id>/seal.png` | 2차 도트 인장. 새김 도장은 이것보다 작고 단순한 버전 |
| `docs/screenshots/characters-contact.png` | 전체 화풍 참고 |

## 2. 만들어야 할 것

### A. 인물별 표정 — `Resources/characters/<id>/` (네 인물)

| 파일 | 원본 | **납품** (4배, nearest) | 투명 | 내용 |
|---|---|---|---|---|
| `reaction-pleased.png` | 64×64 | **256×256** | 투명 | **흡족한 얼굴**. 눈이 살짝 감기고 입꼬리가 올라감. 제갈량은 부채로 입을 가린 미소, 소크라테스는 껄껄 웃음, 니체는 드물게 씩 웃는 한쪽 입꼬리, 세종은 온화하게 고개를 끄덕이는 느낌 |
| `reaction-stern.png` | 64×64 | **256×256** | 투명 | **꾸짖는 얼굴**. 눈썹이 내려오고 입이 굳음. 제갈량은 부채를 접고 정면 응시, 소크라테스는 눈을 가늘게 뜨고 한쪽 눈썹 올림, 니체는 노려봄, 세종은 근엄하게 입을 다물고 눈을 내려봄 |

- 초상(`portrait.png`)과 **머리·옷·배경 위치가 픽셀 단위로 같아야** 합니다. 얼굴 부분만 바뀝니다. 세 장(portrait / pleased / stern)을 겹쳐 보면 얼굴 외엔 차이가 없어야 합니다.

### B. 공통 UI 아이콘 — `Resources/ui/` (새 폴더, 인물 무관)

| 파일 | 원본 | **납품** | 투명 | 내용 |
|---|---|---|---|---|
| `fb-sharp.png` | 24×24 | **96×96** | 투명 | "찔렸다" 아이콘. 화살 한 대가 과녁 가운데 꽂힌 모양, 또는 심장에 바늘. 주홍 `#9b2226` + 먹 `#1c1917` |
| `fb-dull.png` | 24×24 | **96×96** | 투명 | "뻔했다" 아이콘. 하품하는 입 또는 감긴 눈에 zzz 한 개, 또는 무딘(뭉개진) 붓끝. 회갈색 `#6b5e4a` |
| `fb-stamp.png` | 32×32 | **128×128** | 투명 | "새김" 도장. 작은 네모 도장에 한글 **"새김"** 두 글자, 살짝 기울고 찍힌 자국 느낌. 주홍 `#9b2226` |

- 아이콘 세 개는 인물 테마와 무관하게 어느 종이 색 위에서도 보여야 하므로 **외곽선을 먹색으로 분명히** 넣습니다.
- 18px(아이콘)·28px(도장)로 줄여 표시되므로 세부 묘사보다 실루엣이 또렷해야 합니다.

## 3. 작업 방법

1차와 같습니다. 표정은 **초상 원본(64×64)을 열어 얼굴 픽셀만 고치는** 방식을 권합니다. 새로 생성하면 인물이 달라지기 쉽습니다.

납품 전 겹쳐 보기:

```python
from PIL import Image, ImageChops
p = Image.open("Resources/characters/zhuge/portrait.png").convert("RGBA")
for name in ("reaction-pleased", "reaction-stern"):
    r = Image.open(f"Resources/characters/zhuge/{name}.png").convert("RGBA")
    diff = ImageChops.difference(p, r).getbbox()   # 차이가 얼굴 영역 안에만 있어야 함
    print(name, diff)
```
