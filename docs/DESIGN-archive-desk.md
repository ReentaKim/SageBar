# 기획 — 「현자의 서재」 지난 조언 화면 (0.7.0)

> 작성: Claude Code (PM·개발) / 2026-09-22
> 디자인 자산: Astra — `docs/CODEX-REQUEST-desk.md`
> 대체 대상: 현재 `Resources/templates/index.html`(날짜 목록)

## 1. 한 줄 콘셉트

**"현자들이 편지를 써 온 책상을, 모니터 너머에서 내려다본다."**
지난 편지는 목록이 아니라 책상 위에 **쌓인 두루마리**로 보이고, 달마다 묶여 서가에 올라가며, 오늘 차례인 현자가 책상 앞에 앉아 있다. 게임의 인벤토리·파티·장부 화면을 편지 서비스에 옮긴 것.

## 2. 화면 구성 (960×600 장면, 창 폭에 맞춰 비율 유지 축소)

```
┌──────────────────────────────────────────────────────────────────┐
│ [창문]  [서가: 달별 두루마리 묶음 ▭▭▭▭]              [장부 패널] │
│                                                       ┌────────┐ │
│  ┌ 파티 ┐  제갈량  소크라테스  니체  세종               │ 편지 N통│ │
│  └──────┘  (초상, 편지 수, 찔렸다 수)                  │ 연속 N일│ │
│                                                       │ 실천 ▮▮▯│ │
│  ═══════════════ 책상 ═════════════════               │ 반응 집계│ │
│   [등불]   ◙◙◙◙◙◙◙  ← 최근 14통 두루마리 더미        └────────┘ │
│            (인물 색 끈, 반응 도장, 최신이 위)          ┌────────┐ │
│   [붓·벼루]                          [앉은 현자]        │  메뉴  │ │
│                                     (오늘 차례, 숨쉬기) │ 오늘의 │ │
│                                                        │ 새로짓기│ │
│                                                        │ 인물지 │ │

  (0.7.5) 목록은 메뉴 → "목록으로 보기" 오버레이로 이동. 장면만 한 화면.
```

### 요소별 정의

| 요소 | 무엇 | 상호작용 | 데이터 |
|---|---|---|---|
| **책상 더미** | 최근 14통이 두루마리로 겹쳐 쌓임. 최신이 맨 위·오른쬬. 인물별 끈 색(제갈량 주홍, 소크라테스 올리브, 니체 금, 세종 청록) | 마우스 올리면 살짝 떠오르며 말풍선: 날짜·인물 초상·핵심 조언(주제목)·반응 도장. 클릭하면 편지 열기 | `history.jsonl` date/persona/subtitle/feedback/mood |
| **서가 묶음** | 달마다 한 묶음(두루마리 다발). 이번 달은 열린 상태 | 클릭하면 그 달 편지가 책상 위로 펼쳐짐(더미 교체). 다시 클릭하면 최근 14통으로 | 날짜의 연-월 |
| **파티(네 현자)** | 초상 네 개 가로 배치. 아래에 편지 수·찔렸다 수 | 마우스 올리면 그 인물 편지만 책상에 강조. 클릭하면 "이 인물에게 오늘 글 다시 듣기" 2단계 확인(한 번 더 클릭) → `sagebar://regenerate?persona=` | 인물별 집계 |
| **앉은 현자** | 오늘 차례(또는 오늘 편지의) 인물이 책상 앞에 앉아 있음(정지). 글 짓는 중이면 붓 놀림 6프레임(0.7.7) | 클릭하면 오늘 편지 → `sagebar://today` | 기존 `idle.png`/`writing.png` 재사용 |
| **장부** | 통계 패널: 편지 통수, 연속 일수(오늘 포함), 실천 확인 비율(점검 pleased/전체), 반응 집계 세 가지, 인물별 통수 | 없음(읽기) | history 집계, `mood` 필드 신설 |
| **메뉴** | 게임 일시정지 메뉴 느낌의 세로 버튼 4개: 오늘의 편지 / 새로 짓기(누르면 파티가 깜박이며 "인물을 고르십시오") / 인물지 열기 / 설정 | `sagebar://today`, 파티 선택 모드, `sagebar://profile`(신설), `sagebar://settings` | — |
| **창문** | 실제 시각에 따라 아침·낮·저녁·밤 하늘 | 없음 | 현재 시각 |
| **등불** | 2프레임 깜박임. 밤에만 켜짐 | 없음 | 현재 시각 |

### 규칙
- 두루마리는 **최대 14개**만 책상에. 그 이상은 서가로.
- 오늘 편지가 아직 없으면 책상 맨 위에 **빈 종이**가 놓이고 말풍선 "아직 오늘 글이 없습니다 · 클릭하면 짓습니다".
- 반응 도장: 찔렸다=주홍 도장, 뻔했다=회색 도장, 달랐다=엇갈린 표시. 없으면 도장 없음.
- 실천 확인(mood): pleased=금빛 점, stern=주홍 점, neutral=없음 — 두루마리 끝에 작은 점.
- 게임처럼 보이되 **글자는 읽히게**: 말풍선·장부·메뉴는 CSS 텍스트(도트 폰트 아님). 그림은 배경·오브젝트에만.

## 3. 자산 없이도 동작 (폴백)

Astra 자산이 없으면 CSS로 그린다: 나무색 그라데이션 책상, 둥근 사각 두루마리(인물 끈 색), 단색 서가 선반, 창문은 시간대 색 사각형. 기능·배치는 동일. 자산이 들어오면 배경·오브젝트만 그림으로 바뀐다.

## 5. 수용 기준

- 편지가 1통뿐일 때도 어색하지 않다(빈 서가, 두루마리 하나, 장부 "1통 · 1일").
- 두루마리 위에 마우스를 올리면 0.5초 안에 날짜·인물·핵심 조언을 읽을 수 있다.
- 클릭 두 번(서가 → 두루마리)으로 어느 달의 어느 편지든 연다.
- 새로 짓기는 실수로 눌리지 않는다(2단계 확인). `claude` 호출은 확인 뒤에만.
- 자산 없는 폴백과 자산 있는 화면의 배치가 같다(그림만 다름).
- 980×1120 창에서 장면 전체와 접힌 목록 머리가 한 화면에 들어온다.
