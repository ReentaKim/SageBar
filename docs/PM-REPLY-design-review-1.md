검토 의견 감사합니다. 스크린샷으로 짚은 문제(세로 날짜로 밀리는 제목부, 작은 부제, 긴 문단 속 실천 항목)는 그대로 재현되었고, 여섯 항목을 모두 0.6.0에 반영했습니다. 항목별 결정과 수용 기준, 남은 자산 요청을 아래에 정리합니다. 변경 전후 화면은 `docs/screenshots/review-1-before.png`, `review-1-after.png`(같은 원문, 980×1120 창)입니다.

## 1. 우선 적용 — 모두 반영

| 제안 | 결정 | 구현 | 수용 기준 |
|---|---|---|---|
| 오늘의 핵심을 주제목으로 | **채택** | 주제목 = 그날의 핵심 조언 한 문장(프롬프트에 "12~20자, 인물 말투의 청유·명령형, 본문에 근거, 과장 금지" 명시). 편지 종류는 "촉한의 승상 제갈량 · 상소문"처럼 작은 표제로. | 편지를 열었을 때 첫 시선에 오늘 조언이 읽힘. 제목이 본문 소제목·실천 항목 중 하나와 연결됨 |
| 제목부 여백 조정 | **채택** | 세로 날짜 제거, 표제 아래 한 줄 날짜(간지 포함). 제목 아래 여백 축소. | 980×1120 창에서 네 인물 모두 풍경·인물·주제목·첫 소제목 첫 문단이 스크롤 없이 보임 — 확인 완료 |
| '오늘 해볼 한 가지' 강조 | **채택, 두 층으로** | ① 소제목마다 "관찰 → 해석 → 오늘 해볼 한 가지" 흐름과 짧은 실천 문장 마무리를 프롬프트에 명시. ② 0.5.0부터 저장만 하던 실천 항목 3개를 편지 끝 "오늘 행하실 세 가지"(인물별 제목) 번호 목록으로 표시 — 얇은 윗줄 하나로 구분, 카드형 아님. | 편지 끝에서 3초 안에 오늘 할 일 3개를 읽을 수 있음. 본문 문단 밀도는 유지 |

## 2. 정책과 함께 검토 — 반영 범위

### 지난 조언 점검의 판단 기준 — 채택

- 판정을 **했다 / 시도 중 / 안 했다 / 기록으로는 알 수 없다** 네 가지로 늘렸습니다.
- 프롬프트에 "**기록이 없다는 것만으로 안 했다로 판정하지 말 것**, 안 했음을 보여주는 발화(반대로 행동·미룬다고 말함)가 있을 때만 안 했다"를 명시했습니다.
- 표정 규칙: `pleased` = 대체로 했다·시도 중, `stern` = 안 했음이 발화로 확인된 경우에만, `neutral`(기본 초상) = 알 수 없다·반반. 기본값은 neutral입니다.
- 근거 발화 인용은 이미 필수였고 유지합니다.
- 수용 기준: 시험 생성에서 "기록 없음" 항목이 "알 수 없다"로, 표정은 neutral로 나오는지 확인. 0.5.0 시험에서 이미 세 번째 항목이 "기록으로는 알 수 없나이다"로 판정된 사례가 있습니다.

### 피드백 선택지 — 채택 (반영 동작 정의 포함)

세 번째 선택지 **"내 얘기와 달랐다"**(값 `miss`)를 추가했습니다. 반영 동작은 다음과 같이 정의했고, 안내 문구도 그에 맞춰 "새겨 두었습니다. 다음 글을 지을 때 참고합니다."로 바꿨습니다.

| 반응 | 다음 편지에 미치는 영향 |
|---|---|
| 찔렸다 | 프롬프트 "독자의 반응" 절에 집계. 직설 수위·구체성 유지 지시 |
| 뻔했다 | 같은 절에 집계. 일반론 축소, 실제 발화 인용 확대, 다른 각도 지시 |
| 내 얘기와 달랐다 | 같은 절에 집계 + "인물지의 사실을 재확인하고 확인되지 않은 것은 추측임을 드러내라" 지시. **최근 7편 중 2회 이상**이면 다음 편지 생성 직후 인물지를 자동으로 다시 짓습니다(로그에 사유 기록) |

- 아이콘 없이도 글자 버튼으로 동작하며, 아이콘은 아래 자산 요청에 포함했습니다.

## 3. 시각적 마무리 — 채택

- 배경 타일 위에 어두운 막(검정 34%)을 한 겹 얹어 질감 대비를 낮췄습니다. 네 인물 공통이며, 소크라테스의 녹색 질감이 본문과 경쟁하던 것이 가장 크게 줄었습니다.
- 어두운 모드는 인물 CSS의 변수로 이미 대응되며, 막은 두 모드에 같이 적용됩니다.
- 시각 강조는 머리 풍경·캐릭터·인장에 그대로 둡니다.

## 4. 납품 자산 검수 결과 (요청서 4)

- `reaction-pleased.png`, `reaction-stern.png` 네 인물, `Resources/ui/fb-sharp.png`, `fb-dull.png`, `fb-stamp.png` — 규격 검증 전부 통과. 점검 상자와 피드백 버튼에 반영되어 화면에서 확인했습니다. 제갈량의 "부채를 접은" 꾸짖는 얼굴이 특히 잘 맞습니다.
