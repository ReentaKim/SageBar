## 1. 무엇을 만드나

"지난 조언 모음" 화면을 **모니터 너머에서 내려다본 현자의 책상**으로 바꿉니다. 지난 편지는 책상 위에 쌓인 두루마리, 달마다 묶여 서가에 올라간 다발, 오늘 차례의 현자가 책상 앞에 앉아 있는 장면입니다. 게임의 인벤토리·파티·장부 화면 느낌이되, 글자는 모두 CSS 텍스트로 얹으므로 **그림에는 글자를 넣지 않습니다.**

화풍은 1~4차와 같은 조조전풍 도트입니다. 기존 캐릭터(`idle.png`, `writing.png`, `portrait.png`)와 피드백 아이콘(`ui/fb-*.png`)을 장면 위에 그대로 올리므로 팔레트·외곽선 규칙을 맞춰 주십시오.

## 2. 장면 좌표 (원본 240×150 기준, 납품은 4배 960×600)

아래 영역은 앱이 CSS로 오브젝트를 올리는 자리입니다. **배경 그림에서는 비워 두거나 단순한 면으로** 처리하십시오.

```
 x:  0        40        80       120       160   168        236  240
y 0 ┌─────────┬──────────────────────────────┬───┬──────────────┬─┐
    │ 창문     │ 서가 (선반, 다발 자리 8칸)     │   │  장부 패널   │ │
    │ 8~48    │ 56~160, y 6~34               │   │  168~236     │ │
 36 ├─────────┴──────────────────────────────┤   │  y 6~78      │ │
    │ 벽 (은은한 질감)                        │   ├──────────────┤ │
 60 │  [등불 12~28, y 60~84]                 │   │  메뉴 패널   │ │
 70 ├══════════════ 책상 앞 모서리 ═══════════╪═══│  168~236     │ │
    │ 앉은 현자     두루마리 더미               │   │  y 84~144    │ │
    │ 8~40        40~150, y 88~140    붓·벼루 │   │              │ │
    │ y 95~140                      130~160  │   │              │ │
150 └────────────────────────────────────────┴───┴──────────────┴─┘
```

- 책상은 위에서 3/4 각도로 내려다본 나무 판. 앞쪽(아래)이 넓고 뒤쪽(y 70 근처)에 벽과 만납니다.
- 오른쪽 세로 띠(168~236)는 종이 색 패널 두 장이 올라갈 자리이므로 어둡고 단순하게.
- 창문은 **틀만** 그리고 하늘은 비웁니다(별도 하늘 그림을 뒤에 깝니다).

## 4. 확인 방법

```sh
python3 scripts/check-characters.py          # [ui/desk] OK 가 나와야 함
```
검증 스크립트는 위 규격을 이미 알고 있습니다. 자산이 들어오면 화면이 자동으로 그림 모드(`has-art`)로 바뀌므로, `SageBar` 메뉴의 "지난 조언 모두"에서 바로 확인할 수 있습니다. 자산이 없는 동안은 CSS로 그린 폴백 장면이 같은 배치로 나옵니다 — `docs/screenshots/desk-fallback.png` 참고.
